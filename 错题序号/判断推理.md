## 图推
### 自己解法
1. C 元素组成相同，位置类，俩图形绕圈
2. D 元素组成相同，位置类，旋转+轴对称，注意数字外面的圆也是轴对称的
3. D 第一眼以为是属性类看曲直，发现有箭头。然后以为是开闭性，也不是。最后发现每个选项都有两个一样的图形但位置不同，找垂直和非垂直的
4. D 火柴棍，感觉容易考对称性，一看都是中心对称的，选D。注意2的中心对称还是2
5. C 元素组成相似，考虑叠加。去同存异，然后旋转
6. C 先看的是线条交点，看都在框内连了好几条线，怀疑是数框内点。左侧框内点321，右侧也是321.且是封闭图形
7. B 对称，曲直，封闭都不是。数量更不是，图形太简单了。后来想到单行图，可以两个格子两个格子看，观察到前一个格子的下侧在后一个格子的上侧
8. C 选项组成相似，且为黑白图，考虑运算。发现相同的加起来是空，右下角两个黑加起来是空，选C
9. C 箭头方向和第一个空相对？存疑，会不会太简单了
10. D 图案凌乱，考虑属性类。不是曲+直，继续对称心。中心对称和轴对称
11. 。先想的封闭，然后曲直，对称，都不是，真没招了。错在挨个对比，其实只要算总体的数量就能得出结果。
12. B 先想的边的数量，然后是对称，对称轴的数量，都不是。最后只能拆开来看，外框中心对称，里面的图形是对称的
13. C 先看了圆切点数量，又看了圆上交点数量，最后才想起来圆内交点数量，被相切迷惑了
14. A 2，3，4，5，且是不同的元素
15. A 看到鸟以为是生活化图形算开闭数或面数量，然后下意识的看了下笔画数，发现笔画数递增
16. D 先数了锐角个数，然后数边的数量，发现前两行都对得上，但第三行的选项都对不上，最后发现是直角个数。注意，题干里有很多直角，一定要留心，一开始就看直角个数！！！
17. C 功能元素，看功能元素的数量和外框的边数
18. B 一开始看每个面都长差不多直接跳过了。后来想到办法，直接开选项的主面，然后回到展开图里去找对应的面，然后看相邻面对不对
19. C 先看选项间的不同排除AB，然后再对比AD排除D
20. D 找三面公共点，看公共点是否一致。自己一开始数错了
