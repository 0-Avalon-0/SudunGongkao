# 整除
1. 整除：整数A、B，若A/B的商为整数，且余数为0，则称A能被B整除，或者B整除A。通常A、B均为正整数
2. 除尽：两数相除，没有余数，此时即被除数能被除数除尽（包括商是小数）。整除是除尽的一种特殊情况


## 常用数字的整除判定
1. 能被（2，5）（4，25）（8，125）。。。整除的数的数字特性
	- （2，5）：是10的倍数
	- （4，25）：是100的倍数
	- （8，125）：是1000的倍数
	- 看末n位几个0
2. 能被（3，9）整除的数字特性
	- 3：各位数字之和是3的倍数。更简单一点，直接把是3的倍数的数字略过，不用算和
	- 9：各位数字之和是9的倍数。同理消9
3. 能被（7，11）整除的数字特性
	- 7：前项数（不含最后一位）-最后一位 * 2 的结果是否能被7整除（一轮看不出就再算一轮，直到能看出为止）
	- 11：奇项和-偶项和的结果的绝对值是否能被11整除
4. 其他合数（非质数）
	- 快速判断一个数能否被一个合数整除：看这个数能否同时被这个合数的两个互质的因数整除


### 技巧
- 他有的苹果是所有水果个数的3/8：总数是8的倍数，苹果数是3的倍数

# 等差数列
通项及多种求和公式

通项：
- an = a1 + (n-1)d
- m+n+e=p+q+f，则am+an+ae = ap+aq+af

求和：
- Sn = （a1+an）* n/2 = na1+n * （n-1）d/2=nan-n * （n-1）d/2
- 奇数个项求和：Sn = n * 中间项：中间项idx，（n+1）/2
- 偶数个项求和：Sn = n * 中间两项之和/2：中间两项idx，n/2，n/2+1
- 平均数：（a1+an）/2 = Sn/n
- 奇数项的平均数就是中间项！！！
- 偶数项的平均数就是中间两项/2！！！

# 容斥问题
画文氏图，用容斥公式原理
文氏图：画圈表示交集，并集


公式：I（总数）=A+B-A∩B+Y（AB都不包含）
三者容斥：I=A+B+C-A∩B-A∩C-B∩C+A∩B∩C+Y



## 容斥里的极值
- 求最大值：A∩B的最大值=A或B中较小的（几个里最小的）！！！适用于没有告诉总人数，或者Y不等于0！！！
- 求最小值：
  - A∩B最小值：A+B-I：A∩B=A+B-I+Y，此时默认Y取最小即0
  - A∩B∩C最小值：A+B+C-2I:把AB看作一个整体
  - A∩B∩C∩D最小值：A+B+C+D-3I：同理

# 日期问题
闰年：
- 非100倍数的年份：能被4整除是闰年，否则是平年
- 100倍数的年份：被400整除是闰年，否则为平年（2000是闰年，1900不是闰年）

说法：
- 过N天，就是日期往后推N天
- 隔N天，就是日期往后推N+1天
- 每：每（过、隔）N天/星期：每过一天，每隔一天

## 技巧
- 二月有五个星期一，必然2.1，2.8，2.15，2.22，2.29都是星期一
